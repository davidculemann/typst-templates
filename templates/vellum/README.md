## Use it

`main.typ` is self-contained. Download it, or copy it into
[the Typst web app](https://typst.app), and compile:

```sh
typst compile main.typ
```

Needs Typst 0.12 or newer. Set in **Bitter**; if you do not have it installed, change the `font:` argument in the show rule to a family you do have.

The sample fills one page and shows 7 sections (summary, experience, education, skills, certifications, languages, projects),
which is the same render as the card on the hosted gallery.
